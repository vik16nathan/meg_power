# Electrophysiological “Brain Power” Dissipation: MEG Model-Dependent Power Estimates and Regional Metabolic Correlates

Code for Nathan et al., 2026 (_Human Brain Mapping_), generating model-dependent estimates of MEG-visible electrical power and comparing this new quantity with other metrics of cortical metabolism.

Subdirectories:
- *calculate_parcellate_primary_p*: primary dipole P calculation + visualizations (Fig. 1)
- *phantom*: phantom primary P calculation (Fig. 2)
- *process_brainstorm_data*: processing the n=32 subjects' MEG scans for all analyses
- *secondary_p*: Fig. 3 (secondary dipole P; summed secondary P)
- *metabolism_correlations*: Fig. 4-5
